En el archivo comprimido estara el docker-compose.yml, además de una carpeta donde se encuentra el init, en el init esta el script que crea las tablas y inserta las 3000 personas. Solo en necesario correr el "docker-compose up -d" en la carpeta y se hara todo automatico. Al conectarse en pgAdmin y usar el codigo del archivo "CodigoObtenerPosiciones.sql" se pueden ver los casos de prueba.
